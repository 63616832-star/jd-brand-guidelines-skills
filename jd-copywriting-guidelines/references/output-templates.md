# 输出模板

根据任务类型选择模板。可以压缩输出，但不要省略风险判断和首选理由。

## 目录

- UX 文案生成
- UX 评审改写
- 品牌营销文案生成
- 高风险商品/价格/服务文案
- 视觉运营位执行稿
- 快速评审 Sweep

## UX 文案生成

```text
分类：<核心交易/情感陪伴/智能交互/营销种草/客服售后/入口命名>
场景判断：<为什么归入该分类>
用户目标：<用户此刻想完成什么>
推荐文案：
1. ...
2. ...
3. ...
首选：<推荐项与原因>
自检：<简单、可靠、亲切、下一步是否清楚>
```

## UX 评审改写

```text
分类：<触点类型>
原文问题：
- ...
改写：
1. ...
2. ...
首选：<推荐项与原因>
自检：<是否避免责备、黑话、模糊进度、平台视角>
```

## 品牌营销文案生成

```text
触点类型：<品牌主张/活动营销/频道导流/商品种草/服务承诺/情绪陪伴>
版位角色：<头图定调/楼层分流/商品转化/权益解释/即时触达>
用户场景：<目标用户和使用场景>
核心利益点：<用户能得到什么>
策略方向：<情绪主题/任务计划/场景解决/权益转化/品牌心智>
推荐文案：
1. 方向：
   主标题：
   副标题：
   CTA：
2. 方向：
   主标题：
   副标题：
   CTA：
3. 方向：
   主标题：
   副标题：
   CTA：
首选：<推荐项与原因>
风险自检：<可信、清晰、合规、转化、可落地>
```

当输出京东官号小红书/社媒封面文案且候选超过 5 组时，补充：

```text
批量封面自检：
- “别”使用：<共 N 组，是否不超过 3 组>
- 开头方式：<疑问/场景/观点/清单/情绪等是否分散>
- 单组矛盾：<是否每组只突出一个核心矛盾>
- 副标题新增信息：<是否补充对象/场景/京东价值/权益/行动路径>
- 京东购买价值：<是否体现好挑、好找、一站购齐、履约方便或明确权益>
- 类目罗列：<每组是否不超过 3 类>
- 重复词：<心意/体面/提前/备好是否各自不超过 3 次>
- 慎用词：<乱买/慢慢挑/一次看齐/备齐节日感/挑得更像心意是否已避开>
```

## 高风险商品/价格/服务文案

```text
类目/场景：<普通食品/保健食品/运动器材/价格促销/服务承诺/其他>
证据状态：<已有/缺失/需确认>
可写卖点：
- ...
不可写表达：
- ...
安全替代：
1. ...
2. ...
需补充材料：
- ...
```

确认安全边界后，再输出正式文案：

```text
推荐文案：
1. 主标题：
   副标题：
   CTA：
   说明/声明：
首选：
风险自检：
```

## 视觉运营位执行稿

用于主图、商详、会场 Banner、频道卡片、楼层、橱窗图等需要设计落图的场景。

```text
触点：<主图/商详/会场/频道卡片/楼层/Banner>
版位角色：<头图定调/楼层分流/商品转化/权益解释/即时触达>
目标：<点击/领取/加购/下单/理解服务>
主题策略：<这个版位负责建立什么认知，为什么适合该触点>
信息层级：
1. 主标题：
2. 副标题：
3. 利益点：
4. CTA：
候选方向：
1. <方向名>：<主标题> / <副标题> / <CTA>
2. <方向名>：<主标题> / <副标题> / <CTA>
3. <方向名>：<主标题> / <副标题> / <CTA>
画面建议：<主体、场景、信息摆放>
字数建议：<标题/副标题/CTA 限制>
不可使用表达：
- ...
风险自检：<证据、价格、类目、服务承诺、可落图>
```

## 快速评审 Sweep

用于已有文案的快速检查：

```text
清晰：<是否一眼看懂>
用户利益：<是否回答“对我有什么用”>
证据：<数据/价格/承诺是否有来源>
具体：<是否具体但不编造>
语气：<是否简单、可靠、亲切>
风险：<绝对化/虚假低价/类目功效/过度承诺>
改写建议：
1. ...
2. ...
```
