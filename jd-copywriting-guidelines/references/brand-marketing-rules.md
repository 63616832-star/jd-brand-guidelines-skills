# 京东品牌营销文案规则

生成或评审京东品牌文案、营销文案、活动文案、运营话术、权益表达、服务承诺、频道导流和商品种草时使用本规则。涉及商品事实、价格、类目功效、服务承诺或资质证据时，同时读取 `commerce-compliance-gates.md`。

## 目录

- 总原则

- 2. 活动营销与低价表达

## 总原则

京东品牌营销表达要在转化和可信之间保持平衡：

- 直接：把核心利益前置，让用户一眼看到为什么值得点、领、看、买。
- 生活化：使用真实购物场景和大众语言，不用行业黑话或内部运营话术。
- 可信：数据、优惠、服务、资质和排名必须有证据或规则支撑。
- 克制：可以有吸引力，但不制造焦虑、不夸大承诺、不油腻玩梗。
- 可落地：运营位和图内文案要短，主标题、副标题、CTA 层级清楚。

## 写前信息收集

先确认或推断：

- 触点：首页、会场、频道、楼层、商品卡、主图、Push、弹窗、搜索、商详、会员中心等。
- 目标动作：点击、领取、下单、加购、预约、查看规则、咨询、继续浏览等。
- 目标人群：新人、会员、价格敏感用户、品类兴趣用户、复购用户、售后用户等。
- 核心利益：省钱、省时、省心、买得准、送得快、服务有保障、权益更清楚。
- 证据来源：活动规则、价格口径、服务规则、资质材料、数据来源、商品参数。
- 字数和版位：主标题、副标题、按钮、角标、说明文字、图内文案。

## 触点角色与写法差异

先判断触点角色，再写文案。同一个“暑期活动”在不同触点的写法不应相同：

| 触点 | 核心任务 | 写法重点 | 避免写成 |
|---|---|---|---|
| 会场头图 | 定主题、建场景、给进入理由 | 主标题有季节/活动记忆点；副标题落到用户场景或会场内容；CTA 清楚 | 普通楼层标题、商品卖点堆砌、空泛品牌口号 |
| 会场楼层 | 帮用户分流到下一组内容 | 直接说明分类和选择理由，如人群、场景、品类、任务 | 又写一遍会场主题 |
| 频道入口/卡片 | 告诉用户点进去能解决什么 | 突出入口价值和筛选逻辑 | 内部频道名、运营黑话 |
| 商品卡/主图 | 推动理解和转化 | 一个具体卖点 + 用户利益 + 必要证据 | 主题口号、无证据功效 |
| Push/弹窗 | 触发即时动作 | 当前状态 + 明确利益 + 下一步动作 | 长标题、抽象情绪、多个利益并列 |
| 商详/权益说明 | 降低疑虑 | 规则、范围、限制条件说清楚 | 过度承诺、隐藏限制 |

### 会场头图写法

会场头图是用户进入活动后的第一层认知，不只是“好物集合”的标题。写作顺序：

1. 先定主题角度：节令情绪、生活计划、人群任务、场景解决方案、确定性利益。
2. 再定主标题：要有记忆点和画面感，但不能牺牲清晰度。
3. 副标题补足会场价值：说明有哪些场景、品类、权益或选择方式。
4. CTA 给明确动作：去逛、进入会场、查看清单、领取权益等。

可用结构：

- 情绪主题 + 场景落地：`把暑期过成喜欢的样子` / `出游、纳凉、宅家好物都备好了`
- 计划任务 + 会场承接：`暑期计划，从这里开始` / `清凉防晒、亲子出行、宅家好物按场景挑`
- 用户状态 + 解决方案：`夏天很热，生活要轻松` / `从清凉装备到出游好物，帮你少操心`
- 活动利益 + 证据口径：`暑期补贴会场` / `满减、券、补贴按活动规则展示`

会场头图不要默认写：

- “好物一站备齐”“好物都在这里”“精选好物”“品质生活”等无差异泛化表达，除非副标题给出强场景或具体利益。
- “全网最低、错过亏大、闭眼入、必买清单”等焦虑或无证据表达。
- 只堆品类：“防晒/玩水/露营/家电/零食”，没有用户任务和进入理由。
- 只写情绪：“夏日多巴胺”“热爱一夏”，没有会场内容承接。

## 1. 品牌主张

适用场景：品牌主题、品牌标语、品牌宣发、产品升级传播、长期心智表达。

规则：

- 表达京东的可信、效率、服务确定性和生活陪伴，不只喊抽象口号。
- 标题可以更凝练，但副标题必须补足用户价值。
- 避免“第一、唯一、全能、重新定义”等无证据大词。
- 不为了高级感牺牲可理解性。

推荐方向：

- 用“更省心、更确定、更好买”类用户利益表达品牌价值。
- 用真实服务能力支撑品牌感，例如履约、售后、正品、价保、补贴、会员权益。

避免方向：

- 空泛宏大叙事：“开启未来消费新纪元”
- 过度技术化：“全栈智能底座重塑零售体验”
- 无证据领先：“行业第一的购物体验”

## 2. 活动营销与低价表达

适用场景：618、双 11、年货节、秒杀、百亿补贴、券、红包、满减、会场利益点、价格心智宣导。

规则：

- 直接露出具体价格、优惠金额或领取动作；具体信息比概括描述更有吸引力。
- 优先使用用户中心表达：新人价、会员价、专享价、已省、再省、为你领券。
- 额外奖励表达可用：官方补贴价、补贴价、百亿补贴、红包抵、券后价。
- 限时、限量、秒杀、近 N 天低价等稀缺表达必须有真实活动规则支撑。
- 谨慎使用“原价”，避免强化高价心智；需要对比时优先说明用户实际到手利益。
- 横向锚点如“全网低价、低于同款均价”必须有可核验口径，不作为默认推荐。

推荐表达：

- “新人价 20 元”
- “已为你领到 30 元券”
- “券后价 99 元”
- “官方补贴价，到手更省”
- “限时秒杀，早买早享受”

避免表达：

- “全网最低，错过亏大”
- “历史最低，绝对划算”
- “手慢无，不买就亏”
- “原价很贵，现在闭眼入”

## 3. 频道导流与运营话术

适用场景：首页入口、频道楼层、商品集合、榜单、清单、导购卡片、内容化运营位。

规则：

- 用简单直接的语言说明这个入口能帮用户完成什么。
- 用时间、地点、用户状态、目标或购物历史制造场景刺激。
- 榜单、清单、专区要说明筛选逻辑或用户收益，避免只有内部频道名。
- 可适度贴合热点，但热点必须服务理解和点击，不牺牲清晰度。
- 强调用户选择的正向价值，避免贬义、猎奇或冒犯表达。

推荐表达：

- “新手必看的露营清单”
- “周末出游，这些装备先备好”
- “常买好物降价了”
- “适合通勤党的轻便早餐”

避免表达：

- “高潜品类心智运营阵地”
- “奇特好物集合”
- “爆款流量收割专区”
- “懂的都懂，闭眼冲”

## 4. 商品种草

适用场景：商品推荐理由、商品卡片、商详利益点、主图短文案、导购内容、品类会场。

规则：

- 先写用户场景和利益，再写商品属性。
- 功能、参数、材质、规格要翻译成用户可感知的收益。
- 一个版位只突出 1 个核心卖点，最多补充 2 个辅助点。
- 数据、销量、好评、认证、检测、功效和排名必须有来源。
- 涉及食品、保健、器材、美妆、母婴、医疗、金融等敏感类目时，先走合规门禁。

推荐结构：

```text
用户场景 -> 商品属性 -> 用户利益 -> 证据/限制
```

示例方向：

- “通勤路上也好带，小包装随手放进包里”
- “大容量分区收纳，露营餐具不乱放”
- “支持价保服务，买得更安心”

避免方向：

- “提升免疫力，喝出好状态”
- “矫正体态，告别腰背痛”
- “全网销量第一，闭眼买”

### 内容化种草标题与封面文案

适用场景：小红书式封面标题、内容化导购标题、种草笔记、视频封面、频道内容流、买手推荐、好物清单。先写“为什么值得停下来看”，再写“为什么值得买”。标题/封面文案要像购物理由，不像商品说明书。

基础判断：

- 点击来自：用户身份被击中、痛点被说中、结果够具体、损失风险被提醒。
- 收藏来自：清单感、步骤感、可复用、能替用户省决策。
- 转化来自：价格边界、适用人群、使用场景、买后结果、信任证据。
- 评论来自：反常识、真实体验、争议判断、用户想补充自己的经验。

常用高互动结构：

| 类型 | 用法 | 示例句式 |
|---|---|---|
| 结果承诺 | 先给收益，不先讲参数 | `{商品/工具} 让我少花了 {时间/钱/精力}` |
| 避坑止损 | 提醒买错成本 | `别乱买 {品类}，这几个才是真的有用` |
| 身份击中 | 让用户立刻对号入座 | `{人群} 必看，这些 {品类} 更适合你` |
| 权威/经验背书 | 用真实使用经历降疑虑 | `用了 {时间}，还愿意回购的 {品类}` |
| 清单收藏 | 给用户一个可保存的选择包 | `{数量} 个 {场景} 好物，一次整理好` |
| 反常识 | 制造停顿，但要回到事实 | `{低价/小众/冷门}，但真的解决了 {痛点}` |
| 第一人称实验 | 增强真实感 | `我把 {场景问题} 交给了这几个 {品类}` |

可复用标题公式：

- `我买过最不后悔的 {数量} 个 {品类}`
- `{人群} 必看！这些 {品类} 真的能省事`
- `全员 {价格/预算}，但质感不像这个价`
- `用了才知道，原来 {痛点} 可以这么解决`
- `买之前：{怀疑/嫌贵/不信}；买之后：{离不开/真香/省心}`
- `{预算} 内，把 {生活场景} 升级一遍`
- `不管谁 {送礼/搬家/生娃/入职}，我都推荐这个`
- `{时间/场景} 用下来，还想回购的 {品类}`

电商/带货标题要优先回答三个问题：

1. 值不值：价格、预算、到手利益、使用频次、替代成本。
2. 适不适合我：人群、肤质、户型、年龄段、生活状态、使用场景。
3. 买了会不会后悔：真实体验、回购、长期使用、推荐/不推荐、限制条件。

高互动带货方向：

| 方向 | 适合品类 | 写法重点 |
|---|---|---|
| 低价锚点 + 超值感 | 低客单、日用、礼物、平价店铺 | 写清预算，不夸大最低价 |
| 身份人群 + 必看 | 护肤、母婴、家居、数码配件 | 人群必须真实具体 |
| 自用/无广/素人 + 信任补丁 | 好物合集、护肤、美妆 | 只有确认真实时才能写“无广” |
| 买后结果 + 情绪收益 | 家电、收纳、桌搭、生活方式 | 讲生活改善，不堆参数 |
| 反差价格 + 高端效果 | 平替、配件、小家电 | 避免无证据功效或品质暗示 |
| 后悔/不后悔判断 | 母婴、大件、装修、家电 | 说明适用范围和限制 |
| 替你筛选 + 省决策 | 测评、清单、榜单 | 给筛选逻辑，不只堆数量 |
| 送礼场景 + 不出错 | 节日、母婴、生日、伴手礼 | 写清对象、预算和体面感 |

电商类目提示：

- 护肤美妆：优先写肤质、预算、使用感和流程；功效、修复、抗衰、美白、祛痘等表达先走合规门禁。
- 母婴：优先写月龄、妈妈/宝宝使用场景、安全感和少踩坑；安全、医学、发育相关表达必须有依据。
- 小家电/家居：优先写省事、空间、清洁、幸福感、长期使用；避免无证据性能极限和绝对化耐用承诺。
- 平价好物：优先写预算、使用频次、真实场景和“不后悔”；不要用虚假低价、绝对低价或暗示平台外交易。
- 送礼：优先写送给谁、什么场景、预算和不出错；避免冒犯收礼人身份或制造社交焦虑。

### 京东官号社媒输出约束

当用户要求用京东官号、京东官方账号、品牌官方账号发布小红书、社媒封面、节日推广或内容化导购文案时，在“小红书感”之上增加品牌账号约束：文案要有平台真实购买价值，不要只像达人口吻，也不要把京东只放在句尾署名。

生成规则：

- 批量输出 10 组主标题/副标题时，最多 3 组使用“别”开头或以“别”作为核心钩子；其余组分别使用疑问、场景、观点、清单、情绪、任务、利益等开头方式，避免整组都像同一种劝阻标题。
- 每组只突出一个核心矛盾，例如“送礼不确定”“采购太分散”“临近节日来不及”“不知道按谁挑”。不要在一组里同时塞入“纠结、体面、心意、提前、备好”等多个概念。
- 副标题必须提供新增信息，至少补充一种新信息：适用对象、具体场景、京东购买价值、活动权益、服务能力、选择方式或行动路径。不要只是换一种说法重复主标题。
- 每组最多罗列 3 类商品或场景。避免“粽子礼盒、茶酒生鲜、家宴好物、出行用品、清洁家电”式类目堆叠；需要多类目时，优先抽象成“吃的、送的、用的”或“送礼、家宴、出行”。
- 京东必须体现真实购买价值，而不是只在句尾出现品牌名。根据实际活动和证据选择表达：丰富选择、一站备齐、按对象好挑、按场景好找、正品可信、物流履约方便、售后省心、价保/补贴/券等明确权益。缺少活动权益证据时，不要写具体优惠。
- 禁用或慎用以下表达：`乱买`、`慢慢挑`、`一次看齐`、`备齐节日感`、`挑得更像心意`。如需表达相近意思，改写为更具体的用户价值，例如“按对象挑”“按场景找”“把清单先理清”。
- 输出后自动做重复词检查：当一次输出 10 组时，`心意`、`体面`、`提前`、`备好` 每个词在全部主标题和副标题中各自不超过 3 次；如果超出，替换为更具体的场景词或购买价值词。

京东官号批量封面自检：

- 开头方式是否分散：劝阻、疑问、场景、观点、清单、情绪等是否有变化。
- 每组是否只有一个核心矛盾，且副标题是否给了新增信息。
- 京东价值是否进入文案主体，例如好挑、好找、一站购齐、履约方便、权益清楚。
- 商品/场景罗列是否控制在 3 类以内。
- 禁用/慎用词是否已替换，重复词是否已计数。

不要为了互动牺牲可信：

- 不编造“无广、自用、回购、空瓶、实测、用了 N 年”等真实体验。
- 不写无证据的“全网最低、闭眼入、必买、人人适合、效果炸裂”。
- 不用焦虑施压替代价值说明，如“错过后悔一年”“不买就亏”。
- 不把封面标题写满所有卖点；封面只抓一个钩子，正文再解释证据和限制。

## 5. 服务承诺与权益表达

适用场景：配送、售后、价保、正品、会员权益、返豆、优惠券、补贴、保障说明、规则引导。

规则：

- 清晰、简洁、真实，先说明用户能得到什么，再说明限制条件。
- 权益表达要具体到金额、比例、次数、范围、时效或使用方式。
- 服务承诺必须与真实规则一致，不写超出规则的“必达、必赔、无条件、随时退”。
- 限制条件不要藏起来；主文案讲核心价值，说明文字补充适用范围。
- 用用户视角表达权益，减少平台自我表功。

推荐表达：

- “每单最高返 3%”
- “还送 5 元新品券”
- “支持 7 天价保，降价可申请”
- “预计明天送达，以结算页为准”

避免表达：

- “返豆当钱花”
- “平台为您提供全链路履约保障”
- “极速必达，晚到必赔”
- “无条件退换，放心买”

## 6. 情绪陪伴

适用场景：会员成长、节日、年度账单、权益解锁、惊喜反馈、成就反馈、轻运营提醒。

规则：

- 情绪服务于信息，不用情绪替代事实。
- 对权益、奖励、成就可以适度积极，强调用户被重视和专属感。
- 无明确利益或用户刚完成严肃操作时，不要过度庆祝。
- 语气助词和标点只在能增加温度时使用。

推荐表达：

- “恭喜解锁 PLUS 新权益”
- “你的生日福利已准备好”
- “这张券快到期了，看看还能买点啥”

避免表达：

- “你太会买啦！！！”
- “福利炸裂，错过后悔一年”
- “购物车空空如也，快去买买买”

## 转化文案自检

定稿前确认：

- 清晰：用户能否 3 秒内理解核心利益。
- So What：每个功能、权益、参数是否回答“对用户有什么用”。
- 证据：价格、数据、排名、销量、功效、认证、服务承诺是否有来源。
- 具体：能具体就具体，但不能为了具体编造数字。
- 风险：是否存在绝对化、焦虑施压、虚假最低价、过度承诺或类目红线。
- 可落地：标题、副标题、CTA 是否适合目标版位和字数限制。
