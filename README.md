# JD Brand Guideline Skills

This repository contains the stable Codex Skill package for JD brand copy and marketing-expression workflows.

## Stable Package

Install these two Skill folders:

```text
jd-agency-workflow/
jd-copywriting-guidelines/
```

- `jd-agency-workflow`: workflow coordinator for brief intake, rule routing, compliance gates, expressive marketing copy, QA, and handoff.
- `jd-copywriting-guidelines`: JD 16.0 copy rules for UX text, brand marketing copy, low-price and rights expression, product selling points, naming, and commerce-risk gates.
