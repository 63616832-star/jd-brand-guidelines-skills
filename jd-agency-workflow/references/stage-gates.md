# JD Stage Gates

Use these gates to prevent agency-style over-generation and JD guideline drift.

## Gate 1: Brief Intake

Required:

- target surface and placement;
- user state and user benefit;
- business goal and next action;
- deliverables and constraints;
- known facts, assumptions, missing inputs.

Do not proceed to strategy if the task surface or placement role is unclear.

## Gate 2: Rule Routing

Required:

- selected lead role;
- loaded JD guideline source;
- reason this source applies;
- risk priority if multiple sources apply.

Do not draft before loading the dedicated guideline skill for the touched domain.

If the selected domain needs a WIP visual extension, state whether the extension is installed and whether the result will be provisional.

## Gate 3: Compliance And Evidence

Required when copy involves product, price, activity, service, rights, data, certification, ranking, or sensitive category claims:

- category / scene;
- evidence state;
- writable claims;
- unwritable expressions;
- safe alternatives;
- materials to supplement.

If evidence is missing, output risk judgment and safe directions before formal copy.

## Gate 4: Strategy Confirmation

Required:

- real user/business problem;
- touchpoint task;
- core benefit;
- proof boundary;
- message hierarchy;
- success criteria.

Do not move into creative direction if the route cannot fit the target placement.

## Gate 5: Creative Direction

Required:

- 2-3 routes maximum unless the user asks for exploration;
- route name;
- core idea;
- JD brand fit;
- touchpoint fit;
- execution boundary;
- compliance or visual risk.

Reject routes that depend on unverifiable claims, overpressure, off-brand JOY use, title overflow, or nonstandard icon/IP changes.

## Gate 6: Expression Enhancement

Required before execution when the output is eligible for expressive marketing copy:

- expression mode: safe direct, scene vivid, click stronger, brand steadier, or proposal persuasive;
- reader emotion: wanting to save money, avoid effort, buy confidently, find the right product, feel accompanied, or understand the value faster;
- hook mechanism: contrast, scene entry, action trigger, benefit made concrete, or brand trust cue;
- JD boundary: simple, reliable, friendly; no unsupported claim, anxiety pressure, cheap clickbait, or over-poetic abstraction.

If the surface needs transaction certainty or rule explanation, skip expressive enhancement and use direct JD copy.

## Gate 7: Execution

Required:

- confirmed direction;
- loaded source skill;
- placement-specific output template;
- first-choice recommendation;
- risk self-check.

Do not let copy or visual execution create a new strategy without sending it back to strategy.

## Gate 8: QA Review

Required:

- blockers;
- must-fix items;
- recommended improvements;
- launch/readiness judgment;
- next action.

The QA Reviewer can approve only after copy, compliance, visual, and placement rules are checked for the task scope.
