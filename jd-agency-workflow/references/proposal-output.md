# JD Proposal Output

Use this when packaging an end-to-end campaign, review report, or handoff.

## Working Output

```text
当前阶段：
使用角色：
已加载规范：
输入来源：
已确认事实：
关键假设：
缺失资料：
输出：
风险：
推荐下一步：
```

## Campaign / Proposal Skeleton

- Project understanding
- Target JD surface and user scenario
- Business and user problem
- Evidence and compliance boundary
- Strategy: user benefit, message hierarchy, touchpoint task
- Creative direction: recommended route, backup route, rejected route
- Copy system: safe direct version, expressive version, title, subtitle, CTA, rule notes, high-risk alternatives
- Visual system: JOY/IP or placement-specific visual rules, layout direction, asset restrictions
- Touchpoint adaptation: head image, floor, product card, Push, modal, store image, launch screen, as relevant
- QA checklist and launch risks
- Next decisions and materials needed

```text
适用触点：
核心利益：
主表达：
为什么适合京东：
证据边界：
视觉/IP边界：
风险：

```

## Expressive Copy Option Set

Use this set for eligible marketing surfaces:

```text
安全直接版：
场景生动版：
点击更强版：
品牌更稳版：
首选：
为什么更适合京东：

```

## Final Handoff

End with:

- selected recommendation;
- what must not change;
- what can be adjusted;
- remaining evidence or asset needs;
- approval checkpoint;
- next owner or role.
