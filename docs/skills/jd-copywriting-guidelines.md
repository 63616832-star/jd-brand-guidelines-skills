# 京东文案规范 Skill

`jd-copywriting-guidelines` 用于生成、优化、改写和评审符合京东 16.0 规范的中文文案。它覆盖应用内 UX 文案、品牌营销文案、低价优惠表达、权益表达、服务承诺、商品种草和入口命名等场景。

这个 Skill 的目标不是让文案更夸张，而是让文案更像京东：简单、可靠、亲切，能让用户快速理解当前状态、核心利益和下一步动作。

## 当前发布状态

这是当前稳定可发的核心文案 Skill。给同事分发时，建议和 `jd-agency-workflow` 一起使用：

```text
jd-agency-workflow
jd-copywriting-guidelines
```

- `jd-copywriting-guidelines` 负责具体京东文案规则、触点写法和电商风险门禁。
- `jd-agency-workflow` 负责 brief intake、规则路由、阶段门、QA，以及品牌营销场景里的生动表达层。

## 能做什么

### UX 交互文案

适用于 Toast、弹窗、按钮、空状态、报错提示、升级提示、新手引导、客服售后、入口命名和功能命名。

它会优先判断用户当前状态和目标，再输出清楚、短、可执行的文案。例如：

- 验证码、支付、物流、表单校验等核心交易提示
- 空状态、会员权益、节日问候等情感陪伴文案
- AI 功能、新版本、新模式切换等智能交互文案
- 客服、退款、退换货、投诉等售后文案
- 频道、功能、入口、模块等命名建议

### 品牌营销文案

适用于京东品牌主张、活动营销、频道导流、运营话术、商品种草、服务承诺、权益表达和情绪陪伴。

它会把功能、价格、权益、服务和商品参数翻译成用户能理解的利益点，并输出主标题、副标题、CTA、首选理由和风险自检。

典型场景包括：

- 618、双 11、年货节、秒杀、补贴、优惠券文案
- 首页会场、频道楼层、商品卡、运营 Banner 文案
- 新人价、会员价、券后价、补贴价等低价表达
- 配送、价保、售后、正品、会员权益等服务表达
- 商品推荐理由、导购卡片、主图短文案、商详利益点

### 高风险电商文案门禁

当文案涉及商品事实、价格承诺、服务承诺、类目功效、资质认证、销量排名、检测报告或敏感类目时，它会先做合规门禁，再给出安全表达方向。

门禁会检查：

- 是否有真实活动规则、价格口径、服务规则或资质证据
- 是否出现绝对化、虚假最低价、无证据数据、夸大承诺
- 是否涉及普通食品、保健食品、运动器材等类目红线
- 是否需要补充检测报告、批准文号、认证编号或服务规则

## 核心规则

### 简单

使用大众能理解的词汇和短句。删除内部术语、技术黑话、空泛修饰和重复信息。按钮、标题和运营位只表达一个核心动作或利益点。

### 可靠

不编造数据、价格、排名、销量、认证、报告、功效或服务承诺。涉及到手价、补贴、限时限量、价保、配送、售后等信息时，必须以真实规则为准。

### 亲切

用对话式表达替代命令式表达。优先使用用户视角，说明用户能得到什么、能做什么、下一步怎么做。语气可以有温度，但要克制，不油腻、不夸张。

### 用户利益优先

所有文案都要回答至少一个问题：

- 发生了什么？
- 对用户有什么价值？
- 用户下一步可以做什么？

如果是营销文案，还要回答：

- 为什么值得点？
- 为什么值得买？
- 为什么可以相信？

## 限制与禁区

这个 Skill 不提供最终法律意见，也不保证平台审核结果。它只能根据已有规则和证据边界给出更安全的表达方向。

不要用它来：

- 编造检测报告、批准文号、认证编号、专利、销量、评价或排名
- 把没有证据的数据写成事实
- 把普通食品写成有保健、治疗、调理或改善身体功能的产品
- 把运动器材写成能治疗、康复、矫正或缓解疼痛的医疗产品
- 写“全网最低、唯一、第一、100%、必达、必赔、无条件”等无证据绝对承诺
- 隐藏活动、权益、配送、售后、价保等限制条件

遇到证据不足或类目规则不完整时，Skill 会先输出风险判断、安全替代和需补充材料，而不是直接生成上线文案。

```text
jd-copywriting-guidelines/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── copy-rules.md
    ├── brand-marketing-rules.md
    ├── commerce-compliance-gates.md
    └── output-templates.md
```

- `SKILL.md`：触发说明、任务路由、工作流程和高风险停顿规则
- `references/copy-rules.md`：UX 交互文案、报错提示、客服售后、入口命名等规则
- `references/brand-marketing-rules.md`：品牌营销、活动低价、运营话术、权益表达和商品种草规则
- `references/commerce-compliance-gates.md`：商品、价格、服务承诺和敏感类目的合规门禁
- `references/output-templates.md`：生成、评审、高风险门禁和视觉运营位输出模板

## 使用示例

更多可复制的输入与期望输出，请看：

```text
docs/skills/jd-copywriting-guidelines-examples.md
```

如果只是处理单点文案，直接使用 `$jd-copywriting-guidelines`。如果任务涉及 brief、策略、创意方向、多触点输出、会场头图、小红书封面化表达或最终 QA，优先使用 `$jd-agency-workflow`，让它再路由到本 Skill。

为了让输出更稳，建议在 prompt 里尽量写清楚三项信息：

```text
触点类型：
场景判断：
核心利益点：
```

- `触点类型` 决定使用哪套规则，例如 UX 交互文案、品牌营销文案、电商高风险文案或视觉运营位文案。
- `场景判断` 决定语气强度和信息密度，例如开机屏、弹窗、Toast、会场 Banner、商品卡、商详主图的写法不同。
- `核心利益点` 决定文案方向，例如省钱、省心、服务可靠、新版体验、具体权益或商品卖点。

推荐提问格式：

```text
使用 $jd-copywriting-guidelines 写一组京东 APP 16.0 开机屏推广文案。

触点类型：品牌营销文案 / 开机屏
场景判断：用户打开 APP 时看到，用于传达 16.0 新版升级感
核心利益点：新版更简单、更可靠、更好逛，让用户购物更省心
输出要求：给 3-5 组主标题、副标题和 CTA，并推荐首选
```

如果是商品、价格、权益或服务承诺等高风险文案，建议补充：

```text
商品类目：
证据材料：
价格/权益规则：
禁用表达：
```

这样 Skill 会先判断证据边界和风险，再进入正式文案生成。

搭配工作流使用：

```text
使用 $jd-agency-workflow 写一个小红书爆款封面文案。

产品：京东AI购 APP
场景：春节推广
要求：有点击感，但保持京东可信、克制，不夸大 AI 能力
```

这个场景会先由 `jd-agency-workflow` 判断京东边界和表达模式，再调用文案规范做风险自检。

```text
使用 $jd-copywriting-guidelines 优化这个报错提示：您还没有相关订单。
```

```text
使用 $jd-copywriting-guidelines 写 3 组 618 会场主标题、副标题和 CTA，主打百亿补贴和券后价。
```

```text
使用 $jd-copywriting-guidelines 评审这句商品卖点是否安全：改善睡眠，增强免疫，7 天喝出好状态。
```

```text
使用 $jd-copywriting-guidelines 给这个频道入口起名，要求短、好懂、适合站内长期使用。
```

## 默认输出

通常会输出：

```text
触点类型：
场景判断：
核心利益点：
推荐文案：
首选：
风险自检：
```

如果是高风险商品、价格或服务文案，会先输出：

```text
类目/场景：
证据状态：
可写卖点：
不可写表达：
安全替代：
需补充材料：
```

这样可以先确认安全边界，再进入正式文案生成。
