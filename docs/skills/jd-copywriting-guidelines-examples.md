# 京东文案规范 Skill 案例

本文档沉淀 `jd-copywriting-guidelines` 的典型使用方式。每个案例包含推荐 prompt 和期望输出要点，用于帮助使用者更稳定地调用 Skill，也可作为后续修改 Skill 时的人工验收样例。

如果任务是单点文案生成或评审，直接使用 `$jd-copywriting-guidelines`。如果任务需要 brief、策略、创意方向、生动表达层或最终 QA，优先使用 `$jd-agency-workflow`，再由工作流路由到文案规范。

使用案例时，优先补齐三项信息：

```text
触点类型：
场景判断：
核心利益点：
```

涉及商品、价格、权益、服务承诺或敏感类目时，继续补充：

```text
商品类目：
证据材料：
价格/权益规则：
禁用表达：
```

## 0. 工作流测试：小红书封面化表达

### Prompt

```text
使用 $jd-agency-workflow 写一个小红书爆款封面文案。

产品：京东AI购 APP
场景：春节推广
核心利益点：帮用户更快找到年货、礼物和家宴好物
要求：有点击感，但保持京东可信、克制；不要写最低价、最懂你、必买或未经确认的 AI 能力
```

### 期望输出要点

- 识别为京东品牌营销 / 小红书封面化表达，不是普通 UX 文案
- 先明确关键假设：AI 购的能力只能写成“帮助用户更快找到合适选择”
- 输出风格判断或表达诊断，例如春节购物、减少纠结、年货清单、礼物选择
- 给 3-5 组不同方向：安全直接版、场景生动版、点击更强版、品牌更稳版
- 不使用“全网最低、最懂你、必买、闭眼入”等无证据表达
- 推荐首选并说明为什么更适合京东

可接受方向示例：

```text
春节前，先问京东AI购
年货、礼物、家宴好物，少点纠结，多点省心
```

## 0.1 工作流测试：618 会场头图生动表达

### Prompt

```text
使用 $jd-agency-workflow 写一组京东 618 会场头图文案。

触点：会场头图
核心利益点：百亿补贴、券后价
要求：文案更生动，但不要夸大价格和优惠
```

### 期望输出要点

- 先触发价格/补贴表达风险判断
- 把“百亿补贴”“券后价”视为待确认活动机制，不编造具体金额
- 输出安全直接版、场景生动版、点击更强版、品牌更稳版
- 不写“全网最低、历史最低、错过亏大、必买、手慢无”
- 首选理由要同时说明点击力和京东可信边界

## 1. 开机屏推广文案

### Prompt

```text
使用 $jd-copywriting-guidelines 写一组京东 APP 16.0 开机屏推广文案。

触点类型：品牌营销文案 / 开机屏
场景判断：用户打开 APP 时看到，用于传达 16.0 新版升级感
核心利益点：新版更简单、更可靠、更好逛，让用户购物更省心
输出要求：给 3-5 组主标题、副标题和 CTA，并推荐首选
```

### 期望输出要点

- 识别为品牌营销文案，不触发电商高风险门禁
- 主标题短，适合开机屏短曝光
- 副标题表达简单、可靠、亲切，不使用技术黑话
- 不写“行业第一、全新定义、颠覆体验”等无证据大词
- 给出首选理由和画面建议

## 2. 节气海报：芒种

### Prompt

```text
使用 $jd-copywriting-guidelines 写一组京东节气海报文案。

触点类型：品牌营销文案 / 节气海报
场景判断：京东节气海报「芒种」，用于传达节气氛围和品牌陪伴感
核心利益点：借芒种“忙而有序、播种收获”的节气意象，表达京东陪用户把生活安排得更从容
输出要求：给 5 组主标题和副标题，并推荐首选
```

### 期望输出要点

- 使用节气意象，但不过度诗化
- 保持京东语气：温和、克制、可信
- 不硬卖货，不强行写价格、补贴或商品功效
- 可输出画面建议，如麦穗、青绿夏意、晨光、留白

## 3. 端午主会场文案

### Prompt

```text
使用 $jd-copywriting-guidelines 写一组京东端午节活动文案，应用在营销会场的主会场上。

触点类型：品牌营销文案 / 活动营销 / 主会场
场景判断：用户进入端午节营销主会场时看到，用于建立节日氛围并引导浏览会场好物
核心利益点：围绕端午节备礼、家宴、出游、应季消费，让用户更快找到节日所需
输出要求：给 5 组主标题、副标题和 CTA，并推荐首选
```

### 期望输出要点

- 用节日场景引导浏览，如粽子礼盒、家宴、出游、礼赠
- 不写“最低价、限时必抢、错过亏大”等无规则支撑表达
- CTA 直接清楚，如“进入会场”“去逛逛”
- 可补充主会场视觉和楼层分区建议

## 4. 报错提示改写

### Prompt

```text
使用 $jd-copywriting-guidelines 优化这个报错提示：

触点类型：UX 交互文案 / 报错提示
场景判断：用户搜索订单但没有找到相关结果
核心利益点：让用户知道当前状态，并提供下一步查找路径
原文：您还没有相关订单
输出要求：给 3 组改写，并推荐首选
```

### 期望输出要点

- 识别为客服售后与报错提示
- 不让用户觉得是自己的错
- 说明当前状态，并提供下一步
- 推荐方向如“没有找到相关订单，是否要查找以下订单”
- 不滥用“抱歉”，除非是严重错误或平台失误

## 5. 功能上新引导

### Prompt

```text
使用 $jd-copywriting-guidelines 写一组京东 APP 新功能引导文案。

触点类型：UX 交互文案 / 智能交互与功能上新
场景判断：用户首次看到 AI 购助手入口，需要理解这个功能有什么用
核心利益点：帮助用户更快找到合适商品，并知道如何返回普通搜索
输出要求：给 3 组标题、说明和按钮文案
```

### 期望输出要点

- 隐藏技术复杂度，不展示模型、架构、算法术语
- 说明用户价值，而不是平台能力
- 提供清晰路径或回退方式
- 保持术语一致，例如全程使用“AI 购助手”

## 6. 入口命名

### Prompt

```text
使用 $jd-copywriting-guidelines 给一个新频道入口命名。

触点类型：UX 交互文案 / 入口命名
场景判断：站内频道入口，聚合适合家庭日常囤货的商品
核心利益点：让用户一眼理解这里能买到日常需要、适合囤的好物
输出要求：给 8 个名称方向，并说明首选
```

### 期望输出要点

- 先判断是否需要“京东”背书；站内基础入口通常不强加
- 名称短、清晰、好记、容易搜索
- 避免抽象、诗化、生僻或内部自嗨
- 可在描述性命名和行动型命名之间给选择

## 7. 低价活动表达审查

### Prompt

```text
使用 $jd-copywriting-guidelines 评审并改写这句低价活动文案。

触点类型：品牌营销文案 / 活动营销 / 价格促销
场景判断：主会场商品卡角标，想突出优惠
核心利益点：让用户知道现在买更省
价格/权益规则：仅确认有券后价 99 元，未提供全网比价依据
原文：全网最低价，错过亏大！
输出要求：先判断风险，再给 3 个安全替代
```

### 期望输出要点

- 触发价格促销门禁
- 指出“全网最低价”需要可核验口径，缺证据不能写
- 指出“错过亏大”属于焦虑施压
- 安全替代围绕“券后价 99 元”“到手更省”“以结算页为准”

## 8. 权益表达改写

### Prompt

```text
使用 $jd-copywriting-guidelines 改写这个权益表达。

触点类型：品牌营销文案 / 服务承诺与权益表达
场景判断：会员权益卡片，说明返豆权益
核心利益点：让用户清楚知道每单可以获得什么权益
价格/权益规则：每单最高返 3%，具体以页面规则为准
原文：返豆当钱花
输出要求：给 3 组更具体、用户可理解的表达
```

### 期望输出要点

- 权益表达要具体到比例、范围、限制或使用方式
- 用户利益前置，规则限制后置
- 不使用抽象表达让用户猜
- 推荐方向如“每单最高返 3%，以页面规则为准”

## 9. 普通食品卖点风险改写

### Prompt

```text
使用 $jd-copywriting-guidelines 评审这句商品卖点是否安全，并给安全替代。

触点类型：电商高风险文案 / 商品种草 / 普通食品
场景判断：普通食品商详利益点
核心利益点：突出日常饮用方便、口感清爽、独立包装
商品类目：普通食品，非保健食品，非药品
证据材料：没有保健食品批准文号，没有功效检测报告
原文：改善睡眠，增强免疫，7 天喝出好状态
输出要求：先判断风险，再给可写卖点和安全文案
```

### 期望输出要点

- 触发普通食品门禁
- 判断“改善睡眠、增强免疫、7 天喝出好状态”为高风险
- 不写保健、治疗、调理、改善身体功能
- 改写方向聚焦原料、口感、包装、场景、规格
- 需要保留“普通食品，非保健食品，非药品”的边界提醒

## 10. 运动器材去医疗化

### Prompt

```text
使用 $jd-copywriting-guidelines 改写这个运动器材卖点。

触点类型：电商高风险文案 / 商品种草 / 运动器材
场景判断：运动器材主图短文案
核心利益点：突出日常训练、拉伸放松、轻便易用
商品类目：运动器材，非医疗器械
证据材料：没有医疗器械资质
原文：矫正驼背，缓解腰痛，修复脊柱问题
输出要求：先判断风险，再给 3 组安全替代
```

### 期望输出要点

- 触发运动器材/体态管理门禁
- 指出“矫正、缓解腰痛、修复脊柱问题”属于医疗化风险
- 替代为训练、拉伸、体态管理、肩背舒展等表达
- 不承诺治疗、康复或确定效果
- 如涉及效果，使用“辅助、帮助、逐步、因人而异”等弱化词

## 11. 营销权益保真

### Prompt

```text
使用 $jd-copywriting-guidelines 优化这句营销文案。

触点类型：品牌营销文案 / 活动营销 / 下载拉新
场景判断：用户看到下载京东 App 的活动入口
核心利益点：下载后可领取 10 元优惠券
价格/权益规则：确认有 10 元优惠券
原文：下载京东app，得10元
输出要求：给 4 条推荐文案
```

### 期望输出要点

- 必须保留“京东 App”和“10 元”。
- 在下载拉新、领取场景中，可明确为“10 元优惠券”；如果权益类型不确定，应提示需确认，不要删除金额。
- 不把“10 元”泛化为“专属好礼、福利、超值好物”。
- 候选方向可为：

```text
下载京东 App，领取 10 元优惠券
立即下载京东 App，领 10 元优惠券
下载京东 App，10 元优惠券等你领
京东 App，下载即领 10 元优惠券
```

## 12. 下一步动作不机械入文

### Prompt

```text
使用 $jd-copywriting-guidelines 优化这句功能引导文案。

触点类型：UX 交互文案 / 功能引导
场景判断：用户未开启消息通知，页面希望引导开启
核心利益点：开启后可领取惊喜红包
下一步动作：点击开启
原文：开启消息通知，领惊喜红包
输出要求：给 3 条正文文案和按钮文案
```

### 期望输出要点

- 正文必须保留“消息通知”和“惊喜红包”。
- “点击开启”用于按钮或 CTA，不要机械拼进正文。
- 不生成“请重试”“暂时无法完成操作”等与场景无关的报错文案。
- 可接受方向：

```text
正文：开启消息通知，领惊喜红包
按钮：去开启

正文：打开消息通知，惊喜红包不错过
按钮：立即开启
```
