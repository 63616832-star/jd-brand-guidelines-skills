# JD Agency Workflow Skill

`jd-agency-workflow` 是京东品牌规范项目的流程总控 Skill。它不替代具体规范，而是负责把需求送到正确的规则、阶段和输出格式里。

## 适合做什么

- 京东品牌营销文案
- 会场头图、运营 Banner、频道卡片文案
- 小红书封面化表达，但仍保持京东可信边界
- 活动低价、券后价、百亿补贴等表达的风险判断
- 多角色协作：AE brief、策略、创意、文案、QA
- 对已有文案做“合规 + 生动度”双重评审

## 工作流程

1. Intake：收集触点、版位角色、用户状态、业务目标、核心利益点和证据材料。
2. Rule Routing：判断该走京东文案规范、视觉 WIP 扩展，还是只做流程/策略。
3. Compliance Gate：涉及价格、权益、服务、商品卖点或功效时，先过风险门禁。
4. Strategy：定义触点任务、用户利益、信息层级和京东品牌角色。
5. Creative Direction：在京东硬边界内选择表达方向。
6. Expressive Copy Layer：只在品牌营销/运营位/封面化表达中增强钩子和生动度。
7. Execution：输出文案候选、首选理由和风险自检。
8. QA：检查清晰度、用户利益、证据、京东语气和可落地性。

## 生动表达层

这个 Skill 内置了品牌营销场景的生动表达层，用来增强封面钩子、读者情绪、点击理由和信息层级。它不是把社媒话术直接搬进京东，而是在京东可信、克制、可落地的边界内增强表达。

可用在：

- 会场头图
- 运营 Banner
- 频道卡片
- 小红书封面文案
- 品牌提案表达

不默认用于：

- 支付、物流、退款、售后
- 报错、Toast、表单校验
- 权益规则、服务条款、法律声明
- 缺少证据的价格/功效/排名/服务承诺

## 推荐 Prompt

```text
使用 $jd-agency-workflow 写一组京东春节推广小红书封面文案。

产品：京东AI购 APP
场景：春节前准备年货、礼物、家宴好物
目标：吸引点击，突出 AI 帮用户更快找到合适选择
要求：有爆款封面感，但不要写无证据的最低价、最懂你、必买
```

```text
使用 $jd-agency-workflow 评审这组 618 会场头图文案。

请先判断价格/补贴表达风险，再给更生动但安全的改写。
文案：
全网最低价，错过亏大！
```
